# Portfolio Website

This repository contains the source code for my personal portfolio website.

The website is designed to showcase my skills, projects, certifications, and learning journey as an Information Technology student and aspiring Full Stack Developer.

---

## Project Goals

- Build a responsive personal portfolio website
- Practice semantic HTML and structured CSS
- Create clean and reusable UI components
- Add JavaScript for website interactivity
- Showcase my academic and personal projects
- Practice using Git and GitHub for version control
